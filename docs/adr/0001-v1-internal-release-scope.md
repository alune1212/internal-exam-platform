# 内网第一版收敛发布与运维范围

2026-09-09 确认：知试 v1.0.0 面向现有公司内网使用，保留视频学习、练习与错题复习、正式考试及管理报表。当前产品已具备业务闭环，本次按最少必需工作精简仓库与发布流程，没有硬性发布日期，也没有用户报告的待修业务故障。

Windows、签名发布包和跨主机迁移等未采用的历史运维路径，在核清依赖后退出当前代码与维护范围，历史事实保留在 Git 和归档 OpenSpec 中。选择移除这些路径，而不是继续维护备用方案，是为了让第一版实际支持范围与代码、CI、文档一致；以后重新支持这些环境，需要重新验证当时的部署与运维合同。

本次交付包括仓库定版、`v1.0.0` Git 标签和 GitHub 源码 Release，沿用 Docker Compose 构建运行，不提供离线镜像包，暂不升级正式主机。发布版本与现网部署版本分别记录，现网状态仍以 [上线交接](../handoff.md) 为准。

## 清理边界

- 保留现有业务合同、考试快照、鉴权、自动保存与交卷，以及必要的输入校验、数据保护和回归检查。
- 先沿调用关系解除历史工具对 CI、API 和测试的耦合，再删除无用路径；仍被当前功能依赖的共享代码不按目录整体删除。
- 历史未完成验收保持事实原状，不以退出本版范围替代通过验收；当前业务规格同步后再处理相关 OpenSpec 生命周期。
- 现有备份、第二副本和恢复演练的未启用边界沿用当前运维文档；本次不将其补建为发布要求，也不宣称具备已验证的数据恢复能力。

范围与实施顺序已经用户确认，实施记录见 OpenSpec 变更 `simplify-v1-source-release`。
