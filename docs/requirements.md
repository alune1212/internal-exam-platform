# Requirements

## 项目定位

公司内部临时考试与刷题平台，用于短期组织考试、练习刷题和查看基础成绩报表。系统不是完整 LMS，不承担课程管理、复杂权限、消息队列或多租户能力。

## 角色

- 考试人：通过姓名或员工号进入系统，参加练习和考试。
- 系统管理员：导入题库、导入应参人员、配置考试、查看报表。

第一版不实现复杂 RBAC。

## 题型

第一版只支持：

- `single`：单选题
- `multiple`：多选题
- `judge`：判断题

不支持问答题、填空题、简答题、案例分析题。

## 练习模式

- 可刷全部 `active` 状态题目。
- 不计入正式成绩。
- 可以立即显示正确答案和解析。
- 可以记录练习错题。

## 考试模式

- 考试人输入姓名进入考试。
- 开始考试时生成题目快照。
- 正式考试以题目快照为准。
- 考试中自动暂存答案。
- 暂存不是暂停，倒计时继续。
- 允许提前交卷。
- 到时间自动提交。
- 提交后自动判分。
- 提交后显示答案和解析。
- 按配置显示排名。
- 第一版暂不设置及格线。

## 判分规则

- 单选题：用户答案与正确答案一致得分。
- 判断题：用户答案与正确答案一致得分。
- 多选题：用户选择集合与正确答案集合完全一致才得分。
- 多选比较按集合，不按字符串顺序。例如 `A,C` 与 `C,A` 判定为正确。

## 第一阶段原始交付边界

第一阶段原始目标是先完成可运行框架，不一次性完成全部业务：项目结构、后端 app、前端 app、模型、迁移、基础路由、页面骨架、Docker Compose、文档和健康检查。当前完成状态以 `docs/handoff.md` 为准。
