# 正式考试与练习使用指南

## 考试人

- 使用当前 macOS Chrome、macOS Safari、Android Chrome 或 iOS Safari；系统会阻断旧版、内嵌浏览器和未知浏览器。浏览器运行时不依赖公共 Internet，但邮件验证码仍依赖 SMTP 和收件邮箱。
- 可在 `available_from` 前 30 分钟完成姓名、邮箱和可选员工号核验；到点前不能开始。新开考窗口在开考时间后 15 分钟关闭，窗口内开始仍获得完整考试时长，单场最长 2 小时。
- 一次只使用一个设备/页面。换设备时重新收取 OTP 并确认接管；旧设备会失效，已保存答案、题目快照和截止时间不改变。
- 选项会先写入当前 tab 的临时草稿，再按修订号同步服务器。网络短暂中断时不要清理浏览器数据或换 tab；页面会显示待同步，恢复网络后重试。草稿不是暂停，倒计时继续。
- 交卷后立即显示分数和是否通过；管理员仅在全部 attempt 结束后手动、一次性发布答案解析。排名只对管理员可见。

## 主操作员和备份操作员

- 主操作员在当前 Mac 正式宿主负责预检、发布、开考确认、事件记录、考后备份和关闭会话。备份操作员账号默认禁用，只在主操作员不可用时由本地主机命令启用；接管后不得与主操作员同时登录。
- designated host account 可以复用现有受管 Mac 账号，不强制新建账号；但只能由登记的宿主账号运行 Docker Desktop 和 LaunchAgent。MacBook 必须全程接入 AC，电池不能作为正式电源方案。
- 考前 30 分钟允许考试人登录不等于自动开考。主操作员必须确认预检全部通过并到点后人工宣布开考。
- 开考后进入只读运维窗口。只查看运维页、服务状态和必要日志；不改题、不改名单、不导入、不升级、不删除。考试窗口内必须停止开发和 staging 项目，不能存在第二个 formal writer。严重故障无法在边界内恢复时暂停或改期。
- Docker AutoStart/LaunchAgent 只能恢复已选 release；容器恢复、worker healthy 或 status 变绿都不等于批准开考，必须重新完成人工预检。
- 需要处理异常 attempt 时先记录事件：可将记录作废，再通过预览和确认批量发放一次补考。作废不删除快照或审计证据。
- 解析只能在全部记录 terminal 后手动发布一次。不要提前发布，也不能撤销。个人排名只在管理端报表查看，不向考试人展示。

## 练习模式

练习与正式考试共用题库且不隔离。每次作答后立即显示对错、正确答案、选项对比和解析；本次反馈锁定，重新作答会新增一条历史而不是覆盖。错题复习可按一级/二级分类和掌握状态筛选；最后一次答对标记“已掌握”，但历史错误仍保留。练习题可能与正式抽题池重合，题库完整泄露不作为第一阶段阻断目标。

## 考后

确认全部 attempt 已交卷或已处置，按需发布解析，创建 post-exam 配对备份并同步独立加密第二存储，生成证据包，最后执行 Mac 版本的 close-session 命令（命令名以 `ops/macos/` 实际文件为准）。数据默认保留 12 个月，到期仅自动提醒；归档和删除必须由操作员人工确认。

考后必须保留本机备份和独立加密第二存储副本，并记录 writer generation/发布 commit、备份 `SUCCESS` 和 SHA-256。未来迁移 Windows 时不能继续使用已停机 Mac 的旧副本作为回滚依据；目标宿主一旦写入，回切必须先从目标生成新的配对备份。
