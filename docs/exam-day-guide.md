# 正式考试与练习使用指南

当前运行实例是 2026-09-08 验收通过的本机最小部署：应考人员访问
`http://192.168.2.225:8080`，操作员在 Mac 本机访问
`http://127.0.0.1:8081/admin/login`。固定版本、启动方式和当前限制见
[`docs/minimal-macos-deployment.md`](minimal-macos-deployment.md)；验收证据见
[`docs/handoff.md`](handoff.md)。

## 用户与应考人员

- 使用当前 macOS Chrome、macOS Safari、Android Chrome 或 iOS Safari；系统会阻断旧版、内嵌浏览器和未知浏览器。浏览器运行时不依赖公共 Internet，但邮件验证码仍依赖 SMTP 和收件邮箱。
- 在 `邮箱登录` 输入邮箱获取六位验证码；验证码十分钟有效、单次使用、最多五次尝试，重发冷却 60 秒。首次登录的新邮箱验证后进入独立“完成注册”步骤填写显示名称；active 账号获得四小时 session，inactive 账号必须联系管理员重新激活。邮箱登录不受旧的 30 分钟名单窗口限制。
- 已发布且已受邀的考试会立即出现在应考人员列表并显示 `available_from`；到点前不能开始。新开考窗口在开考时间后 15 分钟关闭，窗口内开始仍获得完整考试时长，单场最长 2 小时。
- 邀请邮件只提供同源考试回跳路径，不包含 token、OTP、邀请码或授权凭据；完成登录/注册后仍由后端 scope 检查决定是否可见、开始或读取结果。
- 一次只使用一个设备/页面。换设备时重新收取 OTP 并确认接管；旧设备会失效，已保存答案、题目快照和截止时间不改变。
- 选项会先写入当前 tab 的临时草稿，再按修订号同步服务器。网络短暂中断时不要清理浏览器数据或换 tab；页面会显示待同步，恢复网络后重试。草稿不是暂停，倒计时继续。
- 交卷后立即显示分数和是否通过；管理员仅在全部 attempt 结束后手动、一次性发布答案解析。排名只对管理员可见。
- Profile 只允许编辑显示名称，规范化邮箱只读；显示名称变化不会改写已发布考试的冻结 roster identity 或历史报表。学习、练习和错题复习属于普通用户能力，不自动授予正式考试资格。

## 主操作员

- 操作员在 Mac 本机登录管理端，确认题库、单场名单、考试配置和发布状态，再显式发送邀请。候选入口只对局域网提供 8080；管理入口不向局域网开放。
- 每次开考前确认 Mac、网络和 Docker Desktop 保持运行，候选入口可访问，操作员入口可访问，数据库、backend 和自动交卷 worker healthy，并用真实邮箱申请一次验证码。
- 开考后只处理考试所需的状态查看、异常记录和补考/作废流程；不要在有 `in_progress` attempt 时改题、改已发布名单、升级或删除数据。考试窗口内只允许当前最小 Compose 实例写入。
- Docker Desktop 自动启动或容器恢复后，仍要重新检查服务、worker 和业务入口；恢复不等于数据恢复，也不自动批准开考。
- 需要处理异常 attempt 时先记录事件：可将记录作废，再通过预览和确认批量发放一次补考。作废不删除快照或审计证据。
- 解析只能在全部记录 terminal 后手动发布一次。不要提前发布，也不能撤销。个人排名只在管理端报表查看，不向用户展示。

## 已完成的最小上线验收

- 真实邮箱验证码已收到。
- iPhone 16 Pro Max / Safari 已完成登录、答题、刷新后恢复答案、断网后恢复并同步答案、手动交卷和到时自动交卷；未发现页面或按钮异常。
- Mac 重启后 Docker Desktop 自动启动，平台在几分钟内恢复；未手动执行启动命令，手机入口和管理入口正常，重启前成绩仍保留。

## 练习模式

练习与正式考试共用题库且不隔离。每次作答后立即显示对错、正确答案、选项对比和解析；本次反馈锁定，重新作答会新增一条历史而不是覆盖。错题复习可按一级/二级分类和掌握状态筛选；最后一次答对标记“已掌握”，但历史错误仍保留。练习题可能与正式抽题池重合，题库完整泄露不作为第一阶段阻断目标。

## 考后

确认全部 attempt 已交卷或已处置，按需发布解析并导出成绩。当前最小部署不启用发布包签名、配对备份、独立第二副本或恢复演练；不要把 Docker 镜像或持久卷当作已验证的回滚/恢复方案，也不要执行 `down --volumes`。如需引入备份、恢复或升级流程，必须先停止考试并单独完成方案与验收。
